Ramp's frontend interviews have included both a timed word game and a calendar interface. These exercises test whether state and interactions keep working as requirements accumulate. Rehearse completing a usable baseline before adding features, then check invalid input and repeated actions.

## User interface coding questions

- Build Wordle in a timed assessment.
- Implement a calendar with create, read, update, and delete operations.
- Diagnose independent bugs in an existing application, as seen in earlier take-home experiences.

A full game can be practiced through [Wordle](https://www.greatfrontend.com/questions/user-interface/wordle?utm_source=frontendinterviewhandbook&utm_medium=referral&gnrs=frontendinterviewhandbook). The GreatFrontEnd exercise chooses a random word on launch and does not require dictionary validation; follow the requirements supplied in your actual interview.

Calendar work can be broken down into record editing and date layout. The local CRUD operations in [Users Database](https://www.greatfrontend.com/questions/user-interface/users-database?utm_source=frontendinterviewhandbook&utm_medium=referral&gnrs=frontendinterviewhandbook) cover the first part; calendar positioning and date-specific validation are extensions. Pagination practice in [Data Table](https://www.greatfrontend.com/questions/user-interface/data-table?utm_source=frontendinterviewhandbook&utm_medium=referral&gnrs=frontendinterviewhandbook) is useful for a list view, with sorting and filtering added separately.

## Design and project preparation

For a product-inspired design rehearsal, trace an expense from submission to approval and explain pending, successful, and failed states. In a project discussion, walk through work you owned and the reasons behind its state-management and data-fetching choices.
