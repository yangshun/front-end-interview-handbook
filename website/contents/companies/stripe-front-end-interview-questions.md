Stripe candidates have worked through practical coding, debugging, and integration tasks. Frontend and full-stack schedules can differ, so divide preparation time according to the actual round names in your invitation.

## Coding and integration questions

- Implement validation in stages, then accommodate an accessibility follow-up.
- Merge or transform structured data while preserving earlier requirements.
- Fix defects in an unfamiliar codebase during Bug Squash.
- Extend an existing application by loading local data and connecting an API.

For a smaller transformation exercise, [Data Selection](https://www.greatfrontend.com/questions/javascript/data-selection?utm_source=frontendinterviewhandbook&utm_medium=referral&gnrs=frontendinterviewhandbook) covers filtering and optional merging. A paginated interface can start from [Data Table](https://www.greatfrontend.com/questions/user-interface/data-table?utm_source=frontendinterviewhandbook&utm_medium=referral&gnrs=frontendinterviewhandbook); validation and error recovery would be additional requirements.

The HTML-only [Contact Form](https://www.greatfrontend.com/questions/user-interface/contact-form?utm_source=frontendinterviewhandbook&utm_medium=referral&gnrs=frontendinterviewhandbook) exercise is useful for semantic form structure and submission. It does not require client-side validation, so add that separately when practicing the staged validation task.

## System design questions

- Model domain data, implement a handler against provided API contracts, and discuss a component's interface.
- Design a multi-page frontend flow with shared form state and reusable UI primitives.
- Explain how retries, duplicate submissions, and server-confirmed outcomes affect the user interface.

A component discussion can draw on the configurable columns and rendering requirements in [Data Table system design](https://www.greatfrontend.com/questions/system-design/data-table?utm_source=frontendinterviewhandbook&utm_medium=referral&gnrs=frontendinterviewhandbook). Keep this architectural exercise separate from implementing the paginated table above.
