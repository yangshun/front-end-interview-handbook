---
title: Are you familiar with styling SVG?
---

SVG stands for Scalable Vector Graphics, an XML-based format for two-dimensional vector images. There are several ways to color SVG shapes (including specifying attributes on the element) using inline CSS, an embedded CSS section, or an external CSS file. Each approach has advantages and disadvantages.

Basic coloring can be done by setting two attributes on the node: `fill` and `stroke`. `fill` sets the color inside the object and `stroke` sets the color of the line drawn around the object. You can use the same CSS color naming schemes that you use in HTML, whether that's color names (e.g. `red`), RGB values (e.g. `rgb(255, 0, 0)`), hex values, RGBA values, etc.

```html
<rect
  x="10"
  y="10"
  width="100"
  height="100"
  stroke="blue"
  fill="purple"
  fill-opacity="0.5"
  stroke-opacity="0.8" />
```

The above `fill="purple"` is an example of a _presentational attribute_. Interestingly, and unlike inline styles like `style="fill: purple"` which also happens to be an attribute, presentational attributes can be [overridden by CSS](https://css-tricks.com/presentation-attributes-vs-inline-styles/) styles defined in a stylesheet. Hence if you did something like `svg { fill: blue; }` it will override the purple fill that has been defined.
